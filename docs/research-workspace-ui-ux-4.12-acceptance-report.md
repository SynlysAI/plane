## 1. 交付范围

### 1.1 Phase 0 / Phase 1

- 冻结三核心页信息分级、P1 回归清单与固定 13 阶段映射用例。
- 新增 `buildResearchWorkflow` 纯展示层推导，不修改节点业务对象、顺序与状态机。
- 覆盖空链、共享选题 / 评估、双分析阶段、准备节点、未映射节点、等待人工与失败状态。

### 1.2 Wave A：三核心打样

- 科研总览：当前课题、当前节点、待处理数量与唯一下一步入口形成 Primary Surface；待办与 Supporting 区域降级。
- 研究链：固定 13 阶段 Workflow Rail、真实当前位置、临时查看态、等待人工 / 失败语义与准备节点。
- Agent：400px 右侧 overlay、轻量上下文头部、固定输入、默认折叠运行详情、Tab 焦点圈定与关闭后焦点返回。

### 1.3 Wave B：科研工作对象

- 覆盖研究链列表、报告列表 / 详情 / 提交汇总、项目列表、审批中心、评审、阶段与材料、实验、文献、代码、成果、时间线与 PI 聚合。
- 新增 `ResearchDataSurface` 语义出口：列表画布、筛选工具条、表格滚动容器、详情 Header、详情 Surface 与折叠详情。
- 统一数字 / 日期 / 用量右对齐与 `tabular-nums`，历史与 Trace 类信息默认折叠。

### 1.4 Wave C：设置与支撑

- 覆盖组织架构、系统管理、报告模板、身份映射、平台配置、系统集成、系统审计与全局审计。
- 组织树仅当前选中节点显示“添加子节点”，保留空树新建根节点能力但去除整树重复入口。
- 集成调用日志默认折叠；健康状态、最近成功时间、延迟与审计时间稳定对齐。
