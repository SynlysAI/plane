## 验收结论

| 路径              | 结果                                                                                            |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| 项目与课题 / 课题 | 一级导航与页面标题为“项目与课题”，默认课题视图显示唯一“创建科研项目”主操作，不显示资料/成果操作 |
| 统一创建          | 点击“创建科研项目”后进入项目管理视图，URL 过渡参数自动清理并打开“新建科研项目”对话框            |
| 报告与成果        | 报告视图无“上传课题资料 / 登记成果”；成果视图保留“登记成果”、类型/状态/日期筛选和成果表格       |
| 我的反馈          | 日期筛选显示任意、近 7 天、近 30 天、自定义区间；选择自定义后展示开始/结束日期                  |
| 反馈管理          | 页面为全高双栏，右侧默认显示快照占位；点击记录后展示描述、上下文、截图、历史和处置表单          |
| 控制台            | 业务错误 0；仅保留编辑器 Canvas `willReadFrequently` 性能提示                                   |

## 权限说明

本地演示学生账号未挂公共工作区科研组织关系时，研究列表返回 403 属于预期 ACL 行为。学生具备主组织归属时可直接创建科研项目与周期报告，该行为由 `test_research_browse.py` 的学生 POST 契约固定。
