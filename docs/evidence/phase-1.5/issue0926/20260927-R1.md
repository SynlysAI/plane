# 20260927 R1 上级只读查看学生项目

- 私有科研项目的列表和详情增加 `research_access: "review"`，不写入项目成员，也不伪造 `member_role`。
- 读者范围复用直接导师、组织祖先上的 PI/OWNER，以及该工作区唯一主 PI。同组其他学生和普通工作区成员不在范围内。
- 工作项和页面的读取使用同一判断。创建工作项、创建页面和修改项目设置仍返回 403。
- 侧栏把 `research_access === "review"` 视为可见，并用现有次级文字标「只读」。
- 复核补上项目权限里的访客只读角色，以及状态、成员、周期、模块、视图、估算、标签、历史和评论的读取。这些读取不新增项目成员。
- 工作区访客如果同时是直接导师，项目列表仍包含学生项目。
- 按工作项编号打开、附件、描述版本、链接和反应也可以只读。订阅状态只放行读取。
- 工作区管理员如果只是研究链读者，前端仍保持访客角色，不会提升成项目管理员。
- 契约测试覆盖只读壳和访客导师。当前 `public` 仍是两个私有科研项目，本次没有代指定账号做浏览器点击。
