## 4. 环境晋级流程

1. 本地完成测试并记录命令、结果和截图 / 日志摘要。
2. 将 `ai-naive-workspace` 部署到远程测试机，必须使用 `./scripts/deploy.sh --skip-pull`。
3. 远程先执行只读检查和 dry-run。
4. 执行迁移、故障注入或恢复演练前，记录 commit、数据库备份、卷快照和回退命令。
5. 验收证据标注 `local`、`10.26.15.92:3300` 或 `both`。

## 5. 记录纪律

- 不记录密码、Cookie、API token、完整账号邮箱或用户正文。
- 不把一台机器的测试结果写成另一台机器的结果。
- 不把入口 HTTP 200 写成 Forgejo、Synlora、RAGPortal 或 Workspace Runner 已接通。
