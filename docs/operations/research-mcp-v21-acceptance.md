# 科研链 MCP：本地验收与发布范围

更新日期：2026-10-18。本摘要来自本机保留的测试报告、部署核对和用户人工确认后的真实 MCP 执行/读回记录。没有在本次文档整理中重新运行业务写入或 Docker 测试栈；测试服务器尚未部署验收。

## 发布范围

v1 提供十个只读工具，覆盖科研链、节点、任务/评论、事件、快照、关联资源和有界正文读取。v2.1 增加五类动作，使用 prepare/get/list/execute/cancel 操作工具，通过工作区开关、节点范围授权、业务权限和逐项人工确认控制写入。

文件、论文稿件评审、阶段材料、课题附件、外部引用仍以元数据为界；本版不宣称解析全文或实时查询外部源端 ACL。Agent 事件只投影允许公开的内容，不返回内部推理或原始工具输出。

本次发布不提供科研链/节点创建、任务指派/期限/生命周期操作、自动批准、删除、任意文件或 URL 抓取。v2.2/v2.3 尚未实施。

## 2026-10-18 真实 MCP 写入

用户在 Plane 节点页面开启工作区写入、生成授权并逐项确认。当前聊天中的 Codex 使用该配置，通过 Plane 原生 MCP HTTP JSON-RPC 发起真实调用；连接未永久写入全局客户端配置。操作发生在人工创建的测试科研链/节点，不是正式科研数据。

| 动作                   | 执行结果                                                       | 独立 MCP 读回                                                     |
| ---------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------- |
| `create_task`          | `COMMITTED`，创建草稿、未指派科研任务，产生来源事件和审计 ID   | `read_research_resource(kind=task)` 正文完整，标题/说明/状态一致  |
| `append_task_comment`  | `COMMITTED`，向该测试任务追加一条评论，产生来源事件和审计 ID   | `read_research_resource(kind=task_comment)` 正文完整，内容一致    |
| `append_research_note` | `COMMITTED`，节点追加 `RESEARCH_NOTE`，来源 `MCP`，产生审计 ID | `read_research_resource(kind=event)` 正文完整，类型/来源/内容一致 |
| `save_analysis_draft`  | 代码测试通过                                                   | 本轮尚未进行真实 MCP 业务验收                                     |
| `attach_task_resource` | 代码测试通过                                                   | 本轮尚未进行真实 MCP 业务验收                                     |

已执行的三项后端均返回 `readback=verified`，并通过独立读取工具再次读取。该结论说明后端真实写入及读取闭环成功；未进行自动化浏览器逐元素验收、服务器容量测试或任意真实科研文件解析。

原始 proposal/execution/readback JSON 和测试输出保留在开发机 Git 忽略的根 `output/` 下。此处只发布能力与结果摘要，不上传本地账号、连接密钥、业务 UUID、备份或原始日志。
